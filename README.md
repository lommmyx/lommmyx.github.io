# lommmyx

Personal portfolio for **lommmyx**, an iOS developer.

[Visit the live site](https://lommmyx.github.io/)

## Project

[FontTweak](https://github.com/lommmyx/FontTweak) lets you use custom fonts in iOS apps. Download the dylib from the [latest release](https://github.com/lommmyx/FontTweak/releases/latest).

## Local preview

Run `python -m http.server 8000` and open [localhost:8000](http://localhost:8000/). The site uses HTML and CSS and deploys to GitHub Pages from the `main` branch.
